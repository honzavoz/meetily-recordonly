# Contributing to Record Only

Thank you for improving Record Only. This repository is an independent fork of
[Meetily Community Edition](https://github.com/Zackriya-Solutions/meetily).

## Workflow

1. Fork `https://github.com/honzavoz/meetily-recordonly`.
2. Create a focused branch from the current `main` branch.
3. Add or update tests for behavior changes.
4. Run the relevant tests, lint, build, and packaging checks.
5. Open a pull request against `main` with the problem, solution, and validation
   evidence.

Keep unrelated changes out of the pull request and do not commit credentials,
signing keys, downloaded models, generated release bundles, or user data.
